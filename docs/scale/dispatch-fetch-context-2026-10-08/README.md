# Bound dispatch fetch lifetime

The installed nats.go v1.54.0 `jetstream/pull.go` fetch loop uses `time.After(req.Expires + time.Second)` inside its select loop. Each informational reply restarts that timer. The old adapter ignored the worker context and supplied only `FetchMaxWait(time.Second)`. A controlled core NATS API shim reproduces both an extended pull under repeated status100 replies and ignored cancellation (`before.log`). This is a client transport reproduction, not a replicated JetStream partition proof.

The adapter now passes a child context with a one-second deadline through `FetchContext`. The SDK sets server expiry to roughly900ms using its deadline buffer, closes its batch and unsubscribes when the deadline or parent cancellation fires. The batch releases its child timer when the dispatch loop reads the final error. Handler contexts remain the worker context. No detached fetch goroutine or abandoned subscription is introduced by the adapter.

Focused race controls verify repeated informational replies cannot prolong a pull, cancellation releases the inbox, canceled callers do not contact a consumer, and a real R1 JetStream payload/metadata/confirmed acknowledgment still works (`race-corrected.log`). Existing serial/concurrent stalled-batch cancellation controls also pass. The first positive control attempted to forge a JetStream ACK reply through a core server, which correctly rejected it; `race.log` preserves that test setup failure. It was replaced with a real JetStream delivery, without retrying any matrix seed.

The failed corrected partition seed2 remains failed. Its30.188s fanout gap could also involve delayed NAK/server pending state; no recorded informational reply trace links this reproduction to that gap. Majority-progress raw p99 targets are unchanged, and no full native campaign is restarted. The already active full126 normal qualifier remains at its original source and deadline. This focused regression does not qualify the broader plan, production online GC, native matrices, original24h soak or million-timer physical drain.
