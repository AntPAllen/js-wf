# Mixed lease exclusion mutation

The production shared fixture holds four distinct short effects, three timer
parents, two ordered signal parents and a six-child/twelve-grandchild fan-out.
It SIGKILLs the actual journal leader and checks its exit signal. Four replacement
short effects hold leases before a rival identity attempts to acquire the same
invocation. The intact lease implementation rejects it with ErrHeld. The compiled
private-per-worker-key mutation wrongly admits a rival lease at epoch450, which
is then released. All28 invocations complete, preserving their prefix and epoch
handoff; only then does the mutated named test fail with its escape marker.

The intact test passed in36.49s and the mutant was detected in36.38s. The intact
race run also passes (37.59s including race shutdown). The runner rejects compile
and unrelated-test failures. Original logs and reports are losslessly archived
and compared member-by-member to their downloaded/generated bytes. Independent
checks examine actual named execution and semantic markers, not report booleans.
The original lease report inherited unused CAS/model seed-count fields; the
runner now omits them for this mode. Those fields do not describe these executions.
The fixture source hash matches the committed shared implementation; the recorded
HEAD is2875042 with that fixture edited in the working tree before this commit.

The existing I4 intact/detection pair also passes after sharing the fixture;
`shared-I4-regression.tar.gz` retains those executions. This is two mixed source
mutation categories, not all six. Lease exclusion is proven as a contract here;
the mutant's journal need not corrupt I2 because journal CAS is a separate defense.
The new mixed-leases CI job remains to be observed at the committed source.
