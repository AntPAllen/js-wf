## Limits

Production online GC is not enabled. Legacy migration requires quiesced legacy readers/writers and a correctly configured legacy Store; it does not retire the old manifest. Invocation/signal/live-journal/state/terminal/history destinations and their publication fences still need integration. Arbitrary partition/committed-read behavior, privileged lifecycle controls, large native root/message sizes, full runtime migration, final-source full124/matrices/original24h/million physical drain/release and dependency adoption remain open. Native identity binds the embedded module version and application commit; external Go module file contents were not independently inventoried.

Two initial offline reviewer failures are retained in `reviewer-development-failure/`: a five-record replay was incorrectly expected to have four records, and `runtime_checkpoint` was initially checked under an incorrect field name. The positive checker was corrected; native bodies were not rerun or repaired.
