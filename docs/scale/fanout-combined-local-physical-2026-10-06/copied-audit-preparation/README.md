# Full fanout copied audit preparation

`scripts/run-fanout-copied-audit.py` admits only a fresh absolute copy root,
a successful closed full six-case native donor, a pushed clean main revision and
a complete canonical archive. Before copying it reads every canonical part/member,
checks the embedded manifest and every current donor file, reruns the native
review, checks the selected original store file set and visible task descriptors.
It records descriptor permission limits explicitly. Originals never enter NATS.

The selected runtime/module/external Go inputs must equal the original native
build. The helper and producer bind to committed Git; the actual copied SDK is
captured through `/proc`. Three servers are embedded in that executable.
The helper verifies all 501 invocation/journal/terminal records, all 500 child
results and the parent result on all three clients, original 20-second review
budget, durable census and three distinct public local Jsz queue observations.

The command preserves copy-before/copy-after and unchanged-original inventories,
then rechecks canonical/source/executable/full-cohort/API/local-physical bindings.
`--review-only` performs those checks without starting NATS. Copies qualify only
one selected case each; all six and the enclosing native campaign remain separate.
Syntax and argument parsing checked; actual fresh-copy qualification is pending
successful native preservation and push.
