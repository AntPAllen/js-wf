# Experimental graph publication and collection protocol

`internal/graphpublication` connects the immutable append graph to expiring upload intents and original-head publication CAS. It is a typed protocol over a linearizable authority/object Port, with no native adapter and no production runtime or GC integration.

Each publication/content pair has one permanent authority key and at most one bounded grant containing node/payload coordinates. The metadata keeps its content hash, publication owner and monotonically increasing scoped generation after closure. Fresh publications use fresh scopes and immutable physical names; no global per-content intent map is rewritten or allowed to grow with retained history. This implementation stages fresh payload objects rather than deduplicating them across publications. Canonical roots remain bounded frontiers.

Prepare registers an intent before every physical upload and abandons uncertain upload/read/selection outcomes. Commit verifies the exact canonical base, validates inherited graph receipts and all new grants, then CASes at the original head. It accepts a lost publication reply only by exact canonical quorum-witnessed readback. Collection follows bounded ancestry to protect each selected node/payload across later appends without matching the latest root token. An expired unselected grant at its original head is fenced before closure; conflicted or uncertain outcomes retry/fail closed. Closed generations precede physical deletion. Late uploads cannot publish at a fenced head; delayed deletes cannot affect a fresh scope or generation.

The isolated memory Port provides deterministic linearization and injected interleavings.32 seeds publish1024 records, stage competing forks, verify a separate raw-object/hash/leaf census before and after sweeps, and completely reclaim32 retired graphs. Controls cover both collector-versus-commit winners, committed upload/ready/root reply loss, later replacement after reply loss, foreign destinations/authority scopes, read failure, missing ancestry, schema mismatch, unknown objects, delayed deletion, canceled calls and deep copies.128 repeated-content appends retain one grant per scope with observed400-byte maximum authority values. A paused old upload advances its existing scoped generation to2 after closure, cannot publish, and is reclaimed while keeping the closed generation. Foreign physical owners and malformed acknowledgments/inputs reject.

The initial failed draft is retained in `initial-draft/`: underscore fixture IDs violated the contract, its generation assertion compared different content hashes, and review found unbounded per-content grant growth. The corrected scoped model passes normal/scoped race controls; final-source focused race terminal is pending at preparation. Existing graph publication CI uses normal/race count1/5m, with full event artifacts. No hosted CI acceptance is claimed.

Remaining requirements: integrate this protocol into the shared seeded transport/fault/replay graph; qualify all operation boundaries and wider concurrency/scale; add a versioned native quorum-witnessed authority and isolated immutable-object adapter with crash/lost-reply/permission/namespace checks; support existing owned payload reuse and reader/retention pins; implement legacy import and every canonical runtime destination/writer/reader/reconciler; and complete original native matrices/24h/million physical drain/release gates. The legacy direct-reference collector MUST NOT enumerate these objects. Production collection remains quiescent.
