# Bounded autonomous terminal projection audits

`NewCanonicalTerminalAuditScan` and its modeled constructor add an explicit audit mode. The `graph-terminal-audit` repair-loop kind uses its own system lease and persisted cursor. Each budgeted catalog entry receives one projection lookup; the scanner opens no payload readers and never writes projections. It wakes workers for absent or ordinary valid-JSON mirrors, including healthy mirrors, because catalog metadata has no terminal payload digest. Cadence and scan budget therefore bound healthy audit work; million-workflow audit throughput remains unqualified.

A current/newer valid purge marker suppresses the audit. Malformed JSON/markers and unknown lookups fail closed. Recovery still checks the captured canonical generation/source before dispatch. Workers validate canonical payload ownership and perform revision CAS when a present projection differs. Default missing-only scanning remains available; production admission/collection and native schema are unchanged.
