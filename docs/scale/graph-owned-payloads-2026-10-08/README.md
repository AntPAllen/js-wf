# Reuse an owned graph payload without copying its bytes

`PrepareAppendWithOwned` takes explicit source leaf indices and exact physical payload receipts on the original canonical destination/head. It verifies source membership and the origin's ready grant, destination, original head and retained origin edge before staging new nodes. Commit repeats those checks under its unchanged base and original-head CAS. The prepared reuse map is private and copied; caller descriptor mutations do not alter it. A fresh input with the same content hash reuses the already verified receipt. Different physical receipts for the same content hash in one record are rejected as ambiguous.

No payload upload or origin-grant update is made during reuse. Existing origin leaves stay reachable through append-only extensions, so collection protects the original scope even as root tokens change. Whole-graph retirement clears all references and fences old prepared publishers. Partial compaction must transfer ownership before removing origin leaves; reader retention pins and partial compaction remain unimplemented.

32 seeds make1024 reused references across previously reused leaves, preserve one physical payload object per seed and unchanged origin grants, and completely reclaim32 retired graphs. A1MiB payload remains one exact object after16 further references. Negative controls cover wrong indices/upload names/generations, foreign destinations and origin grants, closed/future-origin/stale heads, ambiguous physical receipts, missing ancestry, cancellation and caller mutation. Both collector-versus-commit winners and retirement of a staged reused append are checked.

The complete15-group graph publication package passes normal3.491s/race47.467s under count1/5m. The uncertain-read callback was then tightened to fail specifically at the original payload grant rather than the first grant read; its final focused race control passes separately. The earlier complete-package test source is retained as `package-run-owned-test.go.txt`. Local regression outputs do not establish native durability, complete shared fault/replay coverage, runtime migration or production online GC. Existing publication CI executes the complete package, including these controls; no hosted CI acceptance is claimed here.

Remaining original plan gates stay open: shared transport replay and fault boundary integration, native versioned quorum-witnessed authority/object adapters and crash/concurrency/scale/permissions, reader/retention ownership and legacy import, every canonical runtime writer/reader/reconciler, full native matrices/original24h/million physical drain/dependency adoption/release.
