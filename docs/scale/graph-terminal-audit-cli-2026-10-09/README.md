# Worker CLI terminal audits

The worker accepts explicit `-graph-terminal-audit`, `-graph-terminal-audit-interval`, and `-graph-terminal-audit-budget`. Enabling requires a selected graph store, active repair loops, a positive interval no greater than ten seconds, and a positive scan budget. Supplying settings while disabled is rejected before plugin loading or connecting. Existing missing-only repair uses its own cadence/budget; the audit adds an independent fenced loop. [Operator configuration](../../graph-terminal-audits.md).

The final race command passes admission controls and actual runner recovery on R1 and a three-replica `WFGRAPH` named domain in 81.140 seconds. It loads a matching race-built handler plugin, repairs reserved Start/Signal publication, completes a native timer, recovers two deleted projections, and then restores two conditionally seeded corrupt projections. The canonical journal bytes are unchanged and legacy `WF_JRN` stays empty. `race.log` and `result.json` retain raw output, actual command exit zero, GOMAXPROCS=4/GOMEMLIMIT=512MiB and unchanged before/after hashes for the four selected CLI files. This is focused scope, not retained full compiler/binary provenance or all operator/worker CLI acceptance.

The first single-CPU R3 run timed out during pending Start/Signal repair before audit assertions; its R1 case passed. `single-cpu-failure/` preserves the actual failure. A four-CPU R3 attempt reached audit corruption setup but encountered `key not found` on an immediate KV read; `pre-revision-fixture/` preserves that result. The fixture now anchors restoration to acknowledged revisions: after a delete the recovered value must exceed the last known projection revision plus the deletion; after corruption CAS it must exceed that acknowledged CAS revision. It waits through missing/older reads within the original two-minute fixture deadline and does not treat an old canonical value as restored. This strengthens verification; no native timeout or recovery target is relaxed. These observations do not prove an exclusive server or CPU cause.

Default auditing remains off.
